# Grafische assets

De sprites in deze map komen uit de **"RTS Pack: Medieval"** van
**Kenney Vleugels — [kenney.nl](https://kenney.nl)**.

- Licentie: **Creative Commons Zero (CC0 1.0 Universal)** — publiek domein.
  Zie `LICENSE-kenney.txt`. Vrij te gebruiken in persoonlijke én commerciële
  projecten; naamsvermelding is niet verplicht maar wordt gewaardeerd.
- Bron opgehaald via een publieke GitHub-mirror van Kenney's assets.

Bestanden zijn hernoemd (`s01`–`s23` = Structure, `e01`–`e21` = Environment,
`u01`–`u24` = Unit) maar verder ongewijzigd. De koppeling van sprite → gebouw
gebeurt in `js/render/atlas.js`.
